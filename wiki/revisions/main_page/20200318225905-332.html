Goal

Replimat is a (mostly) self-replicating and (maximally) cross-compatible building system. It is intended to build most things most people need, and to be lots of fun.

Replimat is Open Source Hardware and an example of the Open Design Movement. An affordable platform for industrial independence.

Methods

  • reduce part count and cost through modularity and reusability. Design parts against the Replimat Grid.
  • favor parts which can be locally reproduced and have wide application
  • enable local production via locally made machines
  • consume waste materials for use as raw materials wherever possible - trash to treasure
  • promote pools of compatible parts, within which innovation can happen as fast as communication
  • insist on openness and wide application of all components, production processes, firmwares and software

Ways to help

  • Join the mailing list
  • Create a wiki account, a page for your project, and upload some photos!
  • Install the Replimat software.
  • Purchase vitamins for the project from the Replimat Amazon wishlist
  • Sign up for a build day.
